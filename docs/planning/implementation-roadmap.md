- Finish architecture and planning documents.
- Confirm the MVP scope and permissions model.

- Build the Tauri desktop shell.
- Implement the React-based chat UI.

- Implement provider abstraction.
- Add tool registry and execution loop.
- Integrate plugin loading and MCP support.

- Add secure credential storage.
- Add task and conversation persistence.
- Add audit logging and recovery workflows.
